# TanGit v1.23.0

## Highlights

- **Find and safely run work from one place**: press `Ctrl/Cmd+Shift+P` to open the global Command Palette on Home, in a repository or in an Editor-only workspace. Search translated or canonical English labels, keywords, IDs and chords for navigation, Git, hunk, conflict, Agent and custom commands. Disabled actions explain their current reason. Execution always revalidates the current tab and repository state, and destructive actions still open only their existing confirmation or preview flows.
- **Start from a repository Overview**: the new Overview section summarizes branch and working-tree state, interrupted operations, collaboration, Agent tasks and recent activity. Ordered attention cards make the next safe action easy to find, with every CTA routed through the shared Command Catalog. Wide and narrow layouts follow available pane width rather than the whole window.
- **Scan command history efficiently**: Command Log rows now distinguish successful, failed and running commands with status icons and badges, compact times and full timestamp tooltips. Independent status, invocation-source and time-range menus join the existing origin tabs and command/output search. Row menus reveal or copy output, and full filtered-log copying remains available.
- **Load history as needed**: the virtualized Command Log initially displays 20 matches and reveals 20 more after real user scrolling reaches the end. Filtering resets the display page without changing canonical records. Stable command IDs preserve exact failure navigation and the reader's row when newer commands arrive.
- **Migrate without changing established workflows**: new profiles can open repositories on Overview. Legacy settings retain their previous landing page through an explicit configured sentinel, and existing section order and visibility are preserved while the new stable `overview` ID can be shown, hidden or reordered. Editor-only folders remain Editor-only.
- **Keep background work bounded**: palette searches cap empty-query suggestions, Overview projects bounded recent activity, and Command Log displays only a bounded page of already-recorded matches. Log publication coalesces notifications and repaints only when visible; no additional activity window or persistent activity database is introduced.

## Compatibility and notes

- Existing direct toolbar, keyboard, context-menu and viewer entry points remain available. Command Catalog adapters reuse the existing Git implementations and their current CAS, checkpoint, confirmation and recovery semantics.
- Overview's Recent activity opens the existing canonical command, Safety Journal, Agent, transfer or workspace viewer directly. Durable records retain their existing stores; command/transfer session data are not migrated into a second database. Explicit notices remain bounded process-local records, while ordinary toasts and progress ticks are not persisted automatically.
- Overview never performs render-time Git, disk, network or Agent Store I/O. Agent loading reuses existing generation/token checks, PR checks are shown only from cached state, and progressive repository loading is not misreported as empty history.
- Dialog focus, keyboard isolation, accessible roles/labels, icon tooltips and narrow-width geometry are covered by headless MyGo tests. Multiplatform native overlay/focus validation is still a release verification requirement, not something inferred from those tests.

## Platforms

Release packages and signed updater archives are built for:

- macOS universal
- Windows AMD64 and ARM64
- Linux AMD64 and ARM64

The updater signing key and the public key in `mygo.json` remain unchanged. This document describes the feature scope; it does not itself publish a version, tag or artifacts.
