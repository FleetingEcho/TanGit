# lazygitGo v1.25.0

## Highlights

- **Better performance in large repositories.** New blobless, treeless, shallow, and sparse clone options reduce download size, while repository performance settings limit expensive file statistics and keep primary lists responsive.
- **Custom themes and a refined workspace.** Create, rename, and manage custom palettes independently of theme selection. The workspace includes updated panes, graphs, scrollbars, settings search, and command palette navigation.
- **Faster Git actions with optional recovery.** Stash, discard, and related actions use faster workspace capture with retries and per-file fallbacks. The Safety journal is **off by default**; enable it in Settings or Recovery & checkpoints when you want recovery points and Undo support for common actions. Rebase, reset, and patch edits still retain recovery points.
- **More flexible history and commit tools.** Filter commits with exact date and time bounds, page through the Reflog, and edit rebase TODO files in a modal.
- **Read-only blame that follows your selection.** Open Blame from file menus for tracked, new, and untracked files. The blame view follows the selected file, prevents file shortcuts from modifying the file, and closes with Escape.
- **Recovery safeguards.** When the Safety journal is enabled, discard recovery snapshots include ignored files, including files created by the editor.

## Additional improvements

- Changes folding and workspace navigation are more consistent.
- Commit-list controls clarify active filters and loaded counts.
- The Reflog search count explains whether more entries can be loaded.
- Action confirmations close immediately while background work continues in the Working card.

## Downloads

macOS universal DMG, Windows x64 and ARM64 installers, and Linux x64 and ARM64 Debian packages. Signed updater archives and SHA-256 checksums are also available.
