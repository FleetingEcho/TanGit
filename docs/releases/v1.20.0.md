# lazygitGo v1.20.0

## Highlights

- **Faster performance**: quiet refreshes only re-read the deferred lists when refs, the safety journal or the worktree list changed, instead of re-reading the full history, reflog and worktree states every ten seconds; untracked-file line counts are cached by size and mtime; per-frame Theme and code-graph layout are memoized; the editor's LSP document features, breadcrumb and sticky scroll no longer copy the full buffer on every frame; the commit file tree and filtered lists are built once per frame instead of sorted and rejoined per row; the Fossil-lane counter cache; the graph layout is reused until the visible list changes.
- **Reading gigantic plain folders**: the plain-folder explorer skips unreadable subtrees (such as procfs/sysfs mounts) and mount points, stops indexing after 25,000 files with a clear warning, and keeps the repository usable instead of failing or stalling on roots that hold a whole system image.
- **Resilient repository open**: an unreadable safety journal no longer aborts the repository; lazygitGo opens it with limited data and explains with a one-time notification. The Changes page reports no file-list loss; the file tree no longer fails on unreadable subtrees.
- **The terminal owns the keyboard**: while the terminal dock has focus, application shortcuts (F6, Ctrl+, F1, Escape, Ctrl+L, digits for sections) stop firing, so a nested lazygit TUI or editor in the shell receives every key; only Ctrl+` (toggle the dock) and Ctrl+F (search the shell) remain. The card header's focus button returns the keyboard to the shell.
- **Repository tab colors**: right-click a tab and pick **Tab color…**; the accent palette plus a full-color picker is available, the choice is remembered per repository and can be reset from the same panel.
- **Shortcut notifications off by default**: the one-line acknowledgement for every shortcut stays quiet; the audit log still records every invocation and operation notifications stay visible. Re-enable in Settings → Behavior if wanted.
- **Linux builds now package only the Debian package**.

## Compatibility and notes

- External assistants are trusted shell commands, not a sandbox or a wire-model provider. They only generate reviewable suggestions. No vendor or model is implied.
- SSH workspaces disable trusted local Continue test commands. Local commands may use the network and modify files in the workspace root.
- Users must explicitly approve conflict-resolution results, patch applications and Continue actions.
- History rewrites are limited to supported single-source commit workflows. Root `new-before` and non-interactive GPG signing are not supported in these workflows.
- Stack publishing is per branch and non-transactional; update-ref operations use local-CAS protection and preview-bound leases.

## Platforms

Native packages are built for:

- macOS universal
- Windows AMD64 and ARM64
- Linux AMD64 and ARM64

The updater signs and verifies update integrity with the same private key used by previous lazygitGo releases; the public key in `mygo.json` remains unchanged.
