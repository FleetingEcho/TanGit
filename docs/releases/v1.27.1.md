# lazygitGo v1.27.1

## Highlights

- Diffs stay readable on machines without `git-lfs`. When an optional filter such as Git LFS is missing, unstaged, untracked and agent-review diffs now fall back to the raw file instead of failing with `git-lfs: not found`. Commands that write to the repository are unchanged.
- Compare refs no longer shows dark lines at the ends of the divider, and the commit list and details sit closer together.
- Overview commit rows have a faint background and border so they stand out on light themes. A custom period now has a reset button, and the Home layout toggle is smaller.

## Downloads

macOS universal DMG, Windows x64 and ARM64 installers, and Linux x64 and ARM64 Debian packages. Signed updater archives and SHA-256 checksums are also available.
