# lazygitGo v1.28.0

## Highlights

- **Pull requests and merge requests.** The PR/MR page lists, searches and filters them, opens one with its description, changed files, commits, checks and review sidebar, and lets you comment, reply, comment on a line, resolve threads and approve. It uses `gh` or `glab`.
- **Git hosting settings.** Server, project, issue links and every remote's web address live in one form. The access token is optional: leave it empty and `gh` or `glab` keep using their own login. A configuration whose host differs from the repository's is flagged before you pick it. Test connection reports success in green.
- **Open on remote** checks that the web page answers first. When it does not, a notification leads straight to Git hosting settings.
- **Commit with a description.** A maximize button beside the commit message opens a larger form with a summary and a description.
- **Edit commit message** is in every commit's menu. It is greyed out, with the reason, when the commit is not on the checked-out branch, an operation is in progress or HEAD is detached.
- **Undo** now also reverses staging and unstaging, ignore rules, and creating or deleting a tag.

## Improvements

- Menu and button labels no longer end with an ellipsis. Progress messages such as "Checking for updates…" keep theirs.
- Multi-line and shortcut tooltips use a card with key badges and monospace identifiers.
- Repositories with no commits no longer show a Git error in Overview.
- The command palette finds Git hosting settings when you type "remote".

## Notes

- "Config PR/MR host" is now **Git hosting settings**, and the settings button that adds an external editor is **Add custom editor**.
- The commit form is a dialog now and no longer has an Amend checkbox. Amend the last commit from the Changes menu.

## Downloads

macOS universal DMG, Windows x64 and ARM64 installers, and Linux x64 and ARM64 Debian packages. Signed updater archives and SHA-256 checksums are also available.
