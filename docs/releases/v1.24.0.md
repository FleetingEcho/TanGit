# lazygitGo v1.24.0

TanGit is now **lazygitGo**. Existing installations update in place, and your
settings, recent repositories and workspaces carry over.

## Highlights

- **The new name, with in-place upgrades**: use **Settings → Updates → Check for updates** in TanGit to receive this build. The signing key is unchanged, so existing installations accept it. macOS keeps its bundle identifier and updates the installed bundle in place. Windows ships a small `TanGit.exe` launcher beside `lazygitGo.exe`, so older shortcuts and the old updater still start the app. Linux archives ship a `tangit` launcher, and the Debian package replaces `tangit`. The terminal command is now `lazygitGo`. [Upgrade details](../guide.md#upgrade-from-tangit)
- **A calmer Overview**: Branch health lists merged, stale and far-behind branches as vertical tabs with their branches beside them, and says so in one line when all are healthy. Working tree shows the total beside one row per state with a share bar, or a single clean line. Card buttons sit in the title row, and each time-range button names its period. Contributors, Code changes and Commit activity each keep their own range and branch handling.
- **Code search that scales**: on macOS and Linux a local Zoekt index is built in the background, with a configurable size limit, per-repository switch and cache management. Search exclusions can be edited and take effect at once, and dependency and generated folders are skipped automatically. Without an index, search falls back to ripgrep and then to the built-in scanner.
- **Softer light themes**: System and GitHub Light no longer use pure white. Panes, controls, borders and muted text read apart, and the backdrop behind the cards is a step darker. The theme list stays ordered by background brightness.
- **Worktrees**: right-click a worktree to open it in the current window, a new tab, your editor or a terminal, compare it with the current worktree, or fetch and pull it without switching.
- **More from the Command Palette**: beyond commands, switch modes with `@` branches, `#` commits (paste a hash, or search by message, author and branch), `/` files, `~` recent repositories and `!` to run a shell command with live output (`Ctrl/Cmd+Shift+P`).
- **Six interface languages**: English, 简体中文, 繁體中文, 日本語, Español and Français, switchable in **Settings → Appearance**.
- **A new README and screenshots**: the README is organised around what you can do, and the screenshots show the open-source Lazygit repository.

## Fixes

- Changing a time range on one Overview card no longer resets another. Loading Code changes or Commit activity used to reset the Contributors card with nothing to read it again.
- Changing the Contributors period reads the history again, because the read covers twice the period. Longer periods were counted from too little history.
- The last Overview card no longer leaves a large gap above the status bar when scrolled to the bottom.
- The Windows upgrade check in CI now starts the GUI launcher with redirected handles and waits for it.

## Compatibility and notes

- Settings, recent repositories, workspaces and updater preferences continue to use the existing `TanGit` user-data directory.
- Debian users have no apt feed. Download the matching `lazygitgo_*.deb` and install it with `sudo apt install ./<downloaded-file>.deb`; it replaces `tangit`.
- **Git 2.32 has not been verified.** See [version and capability evidence](../verification.md#version-and-capability-evidence).
- Multiplatform native window and focus behaviour is still a release verification requirement, not something inferred from the headless tests.

## Platforms

Release packages and signed updater archives are built for:

- macOS universal
- Windows AMD64 and ARM64
- Linux AMD64 and ARM64

The updater signing key and the public key in `mygo.json` remain unchanged.
