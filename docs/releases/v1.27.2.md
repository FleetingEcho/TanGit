# lazygitGo v1.27.2

## Highlights

- The command palette gains pull request and remote commands, plus a first batch of everyday Git commands.
- Recent history multi-select has a Select all checkbox aligned with the row checkboxes and an "N selected" count.
- History and Graph no longer show a stale diff when an empty commit is selected; a notice is shown instead.
- The new palette and commit-detail strings are translated.

## Downloads

macOS universal DMG, Windows x64 and ARM64 installers, and Linux x64 and ARM64 Debian packages. Signed updater archives and SHA-256 checksums are also available.
