# TanGit v1.12.0

## Highlights

- **Operation-aware conflict resolution**: continue, skip and abort merge, rebase, cherry-pick, revert and AM workflows with real Git metadata and fingerprint validation.
- **Durable, per-file conflict recovery**: restore unresolved files, including original conflict markers, binary payloads and unmerged index stages, even after staging or reopening the repository.
- **Visual rebase workspace**: inspect and edit actual Git TODO steps, fixed full-SHA marked bases and rich operation metadata.
- **Precision Git editing**: one-click hunk staging, inverse patches, custom-patch history rewrites and preview-bound stack synchronization plans.
- **AI assistance with an approval boundary**: preview conflict resolutions and change-splitting suggestions from trusted external helpers. Suggestions are revalidated against the source digest before applying. Nothing is staged, committed or continued automatically.
- **Continue preflight**: configurable required and optional checks, recovery checkpoints, result review and explicit overrides.
- **MyGo 0.10**: v0.10.0 compatibility updates, including batch highlighting, quit/relaunch behavior, hover anchoring and genuine foreground-process detection.
- **Polished native UI**: guided conflict actions, mixed staged/unstaged views, icon or guided-only modes, non-inline conflict layouts and connected nested-directory guides.
- **Git 2.56 compatibility**: keep file lists intact with whitespace filtering and recognize quoted or custom bisect completion terms across Git versions.
- **Verification and performance**: real Git operation matrices, OpenSSH focus tests, structured recovery fuzzing, streaming numstat parsing and cancellation-safe diff reuse.

## Compatibility and notes

- External assistants are trusted shell commands, not a sandbox or a wire-model provider. They only generate reviewable suggestions. No vendor or model is implied.
- SSH workspaces disable trusted local Continue test commands. Local commands may use the network and modify files in the workspace root.
- Users must explicitly approve conflict-resolution results, patch applications and Continue actions.
- History rewrites are limited to supported single-source commit workflows. Root `new-before` and non-interactive GPG signing are not supported in these workflows.
- Stack publishing is per branch and non-transactional; update-ref operations use local-CAS protection and preview-bound leases.

## Platforms

Native packages are built for:

- macOS universal
- Windows AMD64 and ARM64
- Linux AMD64 and ARM64

The updater signs and verifies update integrity with the same private key used by previous TanGit releases; the public key in `mygo.json` remains unchanged.
