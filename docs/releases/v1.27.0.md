# lazygitGo v1.27.0

## Highlights

- Follow recent work across repositories from the new **Overview**. Keep several saved Overviews, filter by repository, author or unpushed commits, mark changes as read, customize repository colors, and open a commit's full history without losing your place.
- The redesigned Home screen makes recent repositories easier to scan and manage. Pin important repositories, set remote web addresses, and use the new Dark Modern and Light Modern themes.
- Blame is now a full-file editor gutter with commit-colored ranges, history navigation and compact actions for inspecting each change.
- Commit and file context menus gained grouped history, comparison, copy, worktree and remote actions. Commit statistics load only for visible rows, keeping large histories responsive.
- Pane transitions, narrow-window layouts, editor recovery and command-palette search received substantial polish and reliability fixes.

## Downloads

macOS universal DMG, Windows x64 and ARM64 installers, and Linux x64 and ARM64 Debian packages. Signed updater archives and SHA-256 checksums are also available.
