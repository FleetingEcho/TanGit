# lazygitGo v1.26.0

## Highlights

- **In-app updates are back on Debian and Ubuntu.** When lazygitGo is installed from the `.deb` package, the update dialog downloads the new package, verifies its SHA-256 checksum against the release, and installs it through APT after a system authorization prompt. macOS and Windows keep their existing signed updaters.
- **Faster commit history.** Large histories load and filter more quickly, and the commit list stays responsive while pages are read.
- **Complete file history.** Opening an old commit from a file's history now works across the file's entire history, not only the commits that were already loaded.
- **Safer recovery.** Deleting a Safety journal entry now preserves its recovery data instead of discarding it.

## Additional improvements

- The diff layout button shows the layout currently in use and is highlighted while the diff is side by side, matching the wrap toggle beside it.
- The full-screen diff has a button next to the file path that copies the relative path.
- The Agents tab is hidden by default on new installs. Turn it on under Settings > Workspace sections.
- Fixed the file search shortcut and the icons on discard actions.
- Changed-section headers in the Changes pane are measured within their container.

## Downloads

macOS universal DMG, Windows x64 and ARM64 installers, and Linux x64 and ARM64 Debian packages. Signed updater archives and SHA-256 checksums are also available.
