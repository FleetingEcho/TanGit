# lazygitGo v1.26.1

## Highlights

- Compare refs in **Branch changes** mode to see changes since the common ancestor, or use **Exact difference** to compare the current contents of both refs. The comparison also shows commits unique to each ref and lets you inspect their diffs.
- The terminal opens directly at its docked size. Reopening a hidden terminal restores the same session and panel size, and opening the bottom dock avoids the intermediate blank layout.
- The Changes pane disables its discard button when its file count is zero. The blame view now uses a compact close icon with a tooltip.
- The update checker can fall back to the GitHub release page when the GitHub API refuses the update check.

## Downloads

macOS universal DMG, Windows x64 and ARM64 installers, and Linux x64 and ARM64 Debian packages. Signed updater archives and SHA-256 checksums are also available.
